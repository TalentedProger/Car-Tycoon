🎯 Главная цель
Реализовать механику открытия кейса в стиле CS2, где:

Есть N карточек (любое количество), расположенных горизонтально.

После клика “Открыть” запускается анимация прокрутки.

Стрелка по центру экрана всегда указывает на победителя после анимации.

Алгоритм учитывает:

Отступы (gap, margin) между карточками.

Возможные разные размеры карточек.

Победитель определяется исключительно по позиции стрелки, без предрасчета.

🔍 Алгоритм работы (пошагово)
✅ 1. Структура данных
Есть массив карточек, каждая имеет:

id (уникальный)

logo (путь к логотипу)

name (название автомобиля)

price (цена)

Все карточки уже отрисованы внутри горизонтальной ленты.

✅ 2. Параметры для расчета
arrowCenter — координата центра стрелки (фиксированная точка на экране).

Не используем фиксированную ширину: берем реальные размеры карточек с помощью offsetWidth.

Отступы учитываются автоматически, если берем фактическую ширину с margin через getComputedStyle.

✅ 3. При нажатии “Открыть”
Генерируем случайный индекс победителя:

js
Копировать код
const winnerIndex = Math.floor(Math.random() * cards.length);
Вычисляем смещение так, чтобы выбранная карточка оказалась строго под стрелкой:

Считаем суммарную ширину всех карточек до выбранной + ее половина:

js
Копировать код
let totalOffset = 0;
for (let i = 0; i < winnerIndex; i++) {
    const cardStyle = getComputedStyle(cards[i]);
    const gap = parseFloat(cardStyle.marginLeft) + parseFloat(cardStyle.marginRight);
    totalOffset += cards[i].offsetWidth + gap;
}
const winnerCard = cards[winnerIndex];
const winnerStyle = getComputedStyle(winnerCard);
const winnerGap = (parseFloat(winnerStyle.marginLeft) + parseFloat(winnerStyle.marginRight));
const winnerHalf = winnerCard.offsetWidth / 2;
const targetOffset = arrowCenter - (totalOffset + winnerHalf);
Анимация:

Начальное положение → targetOffset (через CSS transform).

Используем easing (ease-out) для плавной остановки.

✅ 4. После анимации
Победитель = cards[winnerIndex].

Подсвечиваем карточку (glow).

Отображаем данные (название + цена).

Разрешаем повторное открытие.

✅ Ключевые особенности алгоритма
✔ Работает с любым количеством карточек.
✔ Учитывает margin или gap (считает реальные размеры).
✔ Работает при разных размерах карточек.
✔ Победитель определяется только по стрелке после остановки.

✅ Формула смещения (обобщенно)
ini

targetOffset = arrowCenter - (сумма ширин предыдущих карточек + половина ширины победной карточки)
✅ Обязательные требования
Не использовать фиксированные значения ширины или gap.

Не делать предрасчет победителя для анимации (только для вычисления смещения).

Генерация рандома только для индекса победителя.

Стрелка всегда статична, смещается только лента.
