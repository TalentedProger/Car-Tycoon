1️⃣ Универсальная формула для Replit
def card_price(P, r, kappa, m, beta, g=0, n=0):
    """
    P: цена авто
    r: базовая доля дохода (например, 0.00025)
    kappa: коэффициент стоимости +1 бонуса
    m: бонус карточки (+1 … +20)
    beta: степень роста цены для сильных бонусов
    g: процент удорожания при повторной покупке (0.12 = 12%)
    n: номер покупки карточки (0 = первая покупка)
    
    Возвращает цену карточки, округленную до десятых.
    """
    I0 = P * r                    # базовый доход
    C1 = kappa * I0               # цена +1
    C_m0 = C1 * m**beta           # цена бонуса m
    C_mn = C_m0 * (1 + g)**n      # удорожание при повторной покупке
    return round(C_mn, 1)         # округление до десятых

2️⃣ Логика редкости и процентов удорожания
Редкость	m (бонус)	g (удорожание)
Обычная	+1…+3	0.12
Необычная	+4…+6	0.15
Редкая	+7…+10	0.18
Эпическая	+11…+15	0.22
Легендарная	+16…+20	0.28

m выбирается в диапазоне редкости

g применяется для каждой последующей покупки карточки

Базовая цена карточки рассчитывается через формулу C_m0 = C1 * m**beta

3️⃣ Универсальные карточки с названиями и цветами
Редкость	Цвет	Бонус	Название
Обычная	Серый / Белый	+1	Порыв ветра
		+2	Лёгкий старт
		+3	Импульс удачи
Необычная	Зеленый	+4	Свежий поток
		+5	Огонь арены
		+6	Дыхание скорости
Редкая	Синий	+7	Гроза трассы
		+8	Сияние рекордов
		+10	Триумфальная волна
Эпическая	Фиолетовый	+11	Зов легенды
		+13	Вихрь славы
		+15	Крылья победы
Легендарная	Золотой/Оранжевый	+16	Золотая молния
		+18	Сердце бури
		+20	Вечный феникс

Примечание для Replit:

Использовать универсальную формулу для расчета цены каждой карточки, исходя из цены авто и бонуса

Применять процент удорожания g при повторной покупке

Округлять до десятых

4️⃣ Пример вызова функции
# Авто стоит 230000, +5 бонус (Необычная), первая покупка
P = 230000
r = 0.00025
kappa = 23
m = 5
beta = 1.25
g = 0.15
n = 0

price = card_price(P, r, kappa, m, beta, g, n)
print(price)  # вернет цену карточки, округленную до десятых
