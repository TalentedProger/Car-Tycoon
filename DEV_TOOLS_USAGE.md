# Как использовать панель разработчика

## Быстрый доступ

1. **Автоматически в dev режиме**: Красная кнопка "DEV" появляется в правом верхнем углу
2. **В продакшене**: Добавьте `?devtools` к URL (например: `yourapp.com?devtools`)

## Функции панели

### 🔍 Показать данные
- Выводит все текущие данные игры в консоль браузера
- Открывайте F12 → Console для просмотра

### 🔄 Сбросить Intro  
- Очищает только данные вступления
- Пользователь снова увидит intro экраны
- Сохраняет прогресс игры

### 🗑️ Сбросить всё
- **ОСТОРОЖНО!** Полностью очищает все данные игры
- Требует двойного подтверждения
- Пользователь начнет с самого начала

## Безопасность

- Панель видна только в dev режиме или с параметром URL
- Все операции с подтверждением
- Данные удаляются только локально (localStorage)

## Использование в продакшене

**НЕ РЕКОМЕНДУЕТСЯ** давать доступ обычным пользователям к полному сбросу данных.

Для администраторов:
```
https://your-app.replit.dev?devtools
```

## Технические детали

- Использует localStorage API браузера
- Работает только на клиентской стороне
- Мгновенное применение изменений после перезагрузки страницы
