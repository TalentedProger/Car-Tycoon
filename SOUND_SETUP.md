# Настройка звуков для системы кейсов Auto Arena

## Структура папок для звуков

Создайте следующую структуру папок в `client/public/sounds/`:

```
client/public/sounds/
├── case/
│   ├── button_click.mp3          # Клик по кнопке "Открыть"
│   ├── case_lock_click.mp3       # Щелчок замка кейса
│   ├── case_opening.mp3          # Звук открытия кейса (механизм, пар)
│   ├── cards_scroll.mp3          # Шум прокрутки карточек (тихий, механический)
│   ├── scroll_stop.mp3           # Клик фиксатора при остановке
│   └── win_sound.mp3             # Звук выигрыша (короткий, яркий)
```

## Описание звуков

### 1. button_click.mp3
- **Тип**: Звук UI
- **Описание**: Классический клик кнопки
- **Длительность**: 0.1-0.3 секунды
- **Рекомендации**: Короткий, четкий звук нажатия

### 2. case_lock_click.mp3
- **Тип**: Механический звук
- **Описание**: Звук щелчка замка или защелки
- **Длительность**: 0.2-0.5 секунды
- **Рекомендации**: Металлический щелчок, как у сейфа

### 3. case_opening.mp3
- **Тип**: Сложный звуковой эффект
- **Описание**: Звук открытия кейса с механизмом и паром
- **Длительность**: 1-2 секунды
- **Рекомендации**: Комбинация механических звуков + шипение пара

### 4. cards_scroll.mp3
- **Тип**: Фоновый звук прокрутки
- **Описание**: Тихий механический шум прокручивания
- **Длительность**: 3-5 секунд (зацикленный)
- **Рекомендации**: Как барабан игрового автомата, но тише

### 5. scroll_stop.mp3
- **Тип**: Звук остановки
- **Описание**: Четкий клик фиксации результата
- **Длительность**: 0.3-0.6 секунды
- **Рекомендации**: Звук как у рулетки при остановке

### 6. win_sound.mp3
- **Тип**: Звук победы
- **Описание**: Короткая яркая фанфара или звон монет
- **Длительность**: 1-3 секунды
- **Рекомендации**: Радостный, праздничный звук

## Форматы файлов

- **Рекомендуемый формат**: MP3 (хорошее сжатие, поддержка браузерами)
- **Альтернативные форматы**: OGG, WAV
- **Качество**: 128-192 kbps для MP3
- **Частота дискретизации**: 44.1 kHz

## Настройка громкости

В коде все звуки будут воспроизводиться с настраиваемой громкостью:

- **button_click**: 0.3 (30%)
- **case_lock_click**: 0.4 (40%)  
- **case_opening**: 0.5 (50%)
- **cards_scroll**: 0.2 (20%) - фоновый
- **scroll_stop**: 0.4 (40%)
- **win_sound**: 0.6 (60%) - самый заметный

## Реализация в коде

Звуки будут загружаться автоматически и воспроизводиться в нужные моменты:

1. При клике "Открыть" → button_click + case_lock_click
2. При исчезновении кейса → case_opening
3. Во время прокрутки → cards_scroll (зацикленный)
4. При остановке → scroll_stop
5. При победе → win_sound

## Резервные варианты

Если не удается найти подходящие звуки, можно использовать Web Audio API для генерации простых звуковых эффектов программно.
