# Логотипы автомобилей

Эта папка содержит логотипы брендов для отображения в колесе фортуны.

## Структура папок:

Для каждого автомобиля создана папка с ID:

- `/car-5/` - LADA Granta
- `/car-6/` - Renault Logan  
- `/car-8/` - Honda Accord 7
- `/car-9/` - Toyota Corolla
- `/car-11/` - Kia Rio
- `/car-13/` - Ford Focus

## Необходимые файлы:

В каждой папке должен быть файл `logotype.png` с логотипом бренда:

- **car-5/logotype.png** - Логотип LADA
- **car-6/logotype.png** - Логотип Renault
- **car-8/logotype.png** - Логотип Honda
- **car-9/logotype.png** - Логотип Toyota
- **car-11/logotype.png** - Логотип Kia
- **car-13/logotype.png** - Логотип Ford

## Требования к логотипам:

- Формат: PNG с прозрачным фоном
- Размер: 64x64 пикселя (оптимально)
- Стиль: векторные, четкие, узнаваемые
- Цвет: желательно монохромные или с минимальным количеством цветов

## Использование:

Логотипы отображаются в сегментах колеса фортуны под названием и ценой автомобиля.

## Примечания:

- До добавления файлов используется эмодзи 🚗 как заглушка
- Убедитесь в наличии прав на использование логотипов брендов
