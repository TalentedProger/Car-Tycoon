# Звуки для игры Auto Arena

Эта папка содержит все звуковые файлы для футуристического интро.

## Необходимые звуки:

1. **intro_loop.mp3** - Фоновая атмосферная музыка (зациклена, тихая, эмбиент)
   - Воспроизводится на всех экранах интро
   - Автоматически останавливается после завершения выбора автомобиля
   - Рекомендуемая громкость: 30%

2. **start.mp3** - Звук зажигания автомобиля 
   - Воспроизводится при нажатии кнопки "Вперёд" на экране выбора машины
   - Длительность: 2-3 секунды

3. **tick.wav** - Звук тика колеса фортуны
   - Воспроизводится каждые 100мс во время вращения колеса
   - Короткий звук (менее 1 секунды)

4. **win.mp3** - Звук победы/празднования
   - Воспроизводится при выборе цвета автомобиля и переходе к празднованию
   - Радостный, торжественный звук

## Требования к файлам:

- Формат: MP3 (кроме tick.wav)
- Размер: до 2MB для intro_loop.mp3, до 1MB для остальных
- Качество: 128-192 kbps
- Оптимизация для веб-использования

## Стиль звуков:

- **Футуристический** - современные синтезированные звуки
- **Минималистичный** - не слишком яркие или агрессивные
- **Неоновый** - соответствующие цветовой гамме интро
- **Атмосферный** - создающие настроение технологичности

## Примечания:

- Если звуковые файлы отсутствуют, игра работает без звука
- Звуки должны соответствовать общему стилю темного футуризма
- Убедитесь в наличии прав на использование звуков
